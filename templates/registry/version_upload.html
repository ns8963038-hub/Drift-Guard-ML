What the upload is checked against

An artifact is not saved until it passes all five checks. A model that cannot score a batch is worse than no model at all — it fails silently at the moment it is asked to do the one thing it exists for.

  1. The file loads, and what comes out is a scikit-learn estimator.
  2. It exposes predict.
  3. It actually scores a sample drawn from this model's baseline.
  4. Its expected feature names match the baseline's columns.
  5. The file is within the size limit.

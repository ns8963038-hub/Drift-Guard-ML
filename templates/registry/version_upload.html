What the upload is checked against

An artifact is not saved until it passes all five checks. A model that cannot score a batch is worse than no model at all — it fails silently at the moment it is asked to do the one thing it exists for.

  1. The file deserialises with joblib.load.
  2. What comes out has a callable predict.
  3. It scores 50 rows drawn from this model's baseline without raising.
  4. It returns exactly one prediction per row it was given.
  5. Every class it predicts is one the baseline's target actually contains.

File type and size are checked before the gate runs.
